* Version 0.1.0

Initial fork of [[https://github.com/rlister/org-present][org-present]] (upstream commit
=4ec04e1b77dea76d7c30066ccf3200d2e0b7bee9=).

** Added
- Default navigation keys: =n= / =SPC= / right arrow forward and
  =p= / =S-SPC= / left arrow backward.
- =q= quits, =g= / =G= jump to the first/last slide, and =C-c C-1= toggles the
  one-page view.
- Navigation keys are editable-aware: they insert their characters when the
  buffer is read-write and navigate when it is read-only.
- =org-slides-mode= now performs setup and teardown itself: overlays, inline
  images, text scale, read-only mode, and cursor hiding.
- Customization options =org-slides-text-scale=, =org-slides-scale-on-start=,
  =org-slides-display-inline-images=, =org-slides-read-only-on-start=,
  =org-slides-hide-cursor-on-start=, =org-slides-hide-stars-in-headings=, and
  =org-slides-startup-folded=.
- =org-slides-after-navigate-functions= abnormal hook, called with the buffer
  name and current heading.
- ERT test suite under =test/org-slides-test.el=.

** Fixed
- Hiding a complete =#+= line now includes the trailing newline, so
  =#+begin_src= / =#+end_src= delimiters no longer leave blank lines around
  source blocks.
- Literal =#+= lines inside block contents are left visible.
- Exporter option detection (=#+TITLE:=, =#+AUTHOR:=, =#+DATE:=, =#+EMAIL:=)
  is case-insensitive.
- Overlay lists and cursor caches are buffer-local.
- The text scale in use before the presentation is restored on quit.
- =org-slides-next= and =org-slides-prev= respect the one-page view instead of
  narrowing again immediately.
- Previous navigation from the first slide returns to the title slide.
- Replaced obsolete =org-get-last-sibling= and =show-all= calls with
  =org-get-previous-sibling= and =outline-show-all=.

** Changed
- Renamed the package, mode, commands, options, hooks, and internal state from
  the =org-present= names to the =org-slides= names.
