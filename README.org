#+title: org-slides
#+author: James Dyer
#+language: en
#+options: toc:nil num:nil

Minimalist presentation mode for Org buffers, derived from [[https://github.com/rlister/org-present][org-present]].

Each top-level heading is one slide; the text before the first heading is the title slide.  Nested headings stay on their parent slide.

#+DEMO: file:/home/jdyer/.emacs.d/offline-packages/local-packages/org-slides/CHANGELOG.org
#+DEMO-TIMED-MACRO: poop

- Default page/slide keys: =n= / right arrow forward, =p= / left arrow backward.  =SPC= reveals the next list item and =S-SPC= re-shadows the previous one; once the items are exhausted they advance/go back a page.  Revealed items stay revealed when revisiting a slide or sub-page.
- =q= quits, =g= and =G= jump to the first and last slide.
- In read-write mode the letter, space, and quit keys insert their characters instead, so the buffer remains editable.  =C-c C-n= and =C-c C-p= always navigate.
- Hides leading heading stars, complete =#+= keyword lines, and emphasis markers.  Hiding a complete =#+= line also hides its newline, so =#+begin_src= / =#+end_src= delimiters do not leave blank lines around source blocks.
- Literal =#+= lines inside source, example, export, comment, quote, verse, center, special, and dynamic blocks are left visible.
- Long slides are paged automatically, one screenful at a time, in the same window.  The end of the slide is never cut off; =n=/=p= move through the pages and then to the next/previous slide.
- Org list items can be stepped through one at a time: unrevealed items use the `org-slides-bullet-shadow' face, =SPC= or =f= reveals the next item, and =S-SPC= (or =b=/=S-TAB=/=Backspace=) puts the previous item back into shadow.  Nested list items are stepped individually.
- Experimental split-page mode (=org-slides-page-style= set to =split=) narrows to one computed page at a time, shows only that page's content, and displays =SLIDE.PAGE / TOTAL-SLIDES.TOTAL-PAGES= (for example =2.3 / 5.4=) in the mode line.  The title page is slide 0 and top-level headings are numbered 1, 2, 3, ... in document order.  The indicator is shown on every slide by default.  Page breaks fit the window, prefer to start at a nested heading, and can be recomputed after a resize or text-scale change.
- A demonstration pane can run beside the presentation.  A slide can name a demo with a =DEMO= property or a =#+DEMO:= line; the pane shows an Emacs buffer, file, URL, video, shell command, interactive shell, keyboard macro, timed keyboard macro, or the result of an Emacs Lisp expression.  =DEMO-MACRO= and =DEMO-TIMED-MACRO= replay recorded steps after the demo buffer opens.  A manually split right-hand window can be adopted as the demo with =org-slides-demo-use-window=, and =C-c C-f=/=C-c C-b= reveal bullets from the demo buffer.  =d= toggles the pane and =C-c C-o= moves focus between the slide and the demo.
- Macro definitions can live in named Emacs Lisp source blocks in the presentation file.  A block marked =:exports none= stays out of exports and is hidden during the presentation by default.
- The text scale in use before the presentation is restored on quit.
- Overlay and cursor state is buffer-local, so multiple presentations do not clobber each other.
- Optional one-page view with =C-c C-1=; this disables automatic paging and shows the whole buffer.

* Installation

Requires Emacs 27.1+ and Org 9.4+.  The package is a single file.  Add its directory to =load-path= or use =use-package=:

#+begin_src emacs-lisp
(use-package org-slides
  :load-path "~/.emacs.d/local-packages/org-slides"
  :commands org-slides-start
  :bind (:map org-mode-map
              ("C-c P" . org-slides-start)))
#+end_src

=C-c P= is used for the example binding because =C-c s= is the global
=spelling-menu= prefix; binding a key below =C-c s= would make that prefix
shadow the spelling menu in Org buffers.

If you also bind =C-c T= to =org-slides-timed-macro-toggle=, add that
command to =:commands= (or autoload it explicitly).  With a deferred
=use-package= form, the key can otherwise be pressed before the package
is loaded, which signals =Wrong type argument: commandp=:

#+begin_src emacs-lisp
(use-package org-slides
  :load-path "~/.emacs.d/local-packages/org-slides"
  :commands (org-slides-start org-slides-timed-macro-toggle)
  :bind (("C-c T" . org-slides-timed-macro-toggle)
         :map org-mode-map
         ("C-c P" . org-slides-start)))
#+end_src

In the offline toolkit the package lives under =local-packages/org-slides= and is loaded automatically by the rendered =init.el= when present.

* Usage

Open an Org file and run =M-x org-slides-start= (or =C-c P= if you added the binding above).  The current slide is narrowed to the window and the text is enlarged.  If a slide is taller than the window, =n= first scrolls through it one screenful at a time; another =n= at the end moves to the next slide.  =p= walks back through those pages.  Going back from the first page of a slide lands on the previous slide's last page, so =p= traverses every sub-page in reverse before reaching the slide start.  At the last page of the last slide, =n= stays put and reports the end of the presentation instead of wrapping back to the start of the same slide.  Use the navigation keys below.  =q= or =C-c C-q= quits.

For the experimental page-narrowing style, set:

#+begin_src emacs-lisp
(setq org-slides-page-style 'split)
#+end_src

Each tall slide is then split into pages that fit the window.  Only the current page's content is displayed, and the mode line shows =SLIDE.PAGE / TOTAL-SLIDES.TOTAL-PAGES= (for example =1.2 / 5.3=).  The total slide count is the number of top-level headings; the title page is slide 0 and is not included in that total.  By default the indicator is shown on every slide, including single-page slides and the title slide; set =org-slides-page-indicator= to =split= to show it only when a slide has more than one page.  Pages break at line boundaries; when possible, a break is moved back to a nested heading so the heading starts the next page.

* Demonstrations beside the presentation

A slide can run a demonstration in a side window.  Put a =DEMO= property in the slide, or a =#+DEMO:= line anywhere in the slide body:

#+begin_src org
,* Live demo
#+DEMO: buffer:*Python*

,* Video demo
#+DEMO: video:~/videos/demo.mp4

,* Shell demo
#+DEMO: shell:

,* Command demo
#+DEMO: command:python3 demo.py

,* Recorded demo
#+DEMO: shell:
#+DEMO-MACRO: my-shell-demo

,* Self-playing macro
#+DEMO: macro:my-demo
#+end_src

The pane opens when the slide is entered and closes when a slide without a demo is entered.  Set =org-slides-demo-default= to use one demo throughout the presentation, or =org-slides-demo-keep= to keep the previous slide's demo.  =#+DEMO: none= hides the pane explicitly.  =#+DEMO:= lines are hidden like other =#+= keyword lines, and a literal =#+DEMO:= inside a source or example block is ignored.

The supported specs are:

| Spec             | Meaning                                                        |
|------------------+----------------------------------------------------------------|
| =buffer:NAME=    | Show an existing Emacs buffer.                                 |
| =file:PATH=      | Visit a file; video extensions are played as video.            |
| =url:URL=        | Open a page with xwidget-webkit when available, otherwise EWW. |
| =video:PATH=     | Play a video in the side window when xwidgets are available.   |
| =video:URL=      | Play a video URL the same way.                                 |
| =command:CMD=    | Run a shell command and show its output and exit status.       |
| =shell:NAME=     | Start or reuse an interactive shell; NAME is optional.         |
| =macro:NAME=     | Play a named keyboard macro in the demo pane.                  |
| =timed-macro:NAME= | Play a timed macro with its recorded delays.                 |
| =elisp:FORM=     | Evaluate FORM; it must return a buffer, a demo spec, or nil.   |
| =external:PATH=  | Open a file or URL outside Emacs.                              |
| =none=           | Hide the demo pane for this slide.                             |

A bare path is treated as =file:= and a bare URL as =url:=.  The default spec is =nil=; set it in your configuration to reuse one demo:

#+begin_src emacs-lisp
(setq org-slides-demo-default "buffer:*scratch*")
(setq org-slides-demo-width 0.4)        ; float is a frame fraction
(setq org-slides-demo-side 'right)      ; or 'left
(setq org-slides-demo-video-player "mpv --no-terminal")
(setq org-slides-demo-video-backend 'auto) ; 'xwidget or 'external
#+end_src

With =video:=, =auto= uses an xwidget web view inside the side window when Emacs was built with xwidgets and is running on a graphical frame.  Otherwise it launches =org-slides-demo-video-player=: =nil= uses the system handler, a string is a shell command with the file or URL appended, and a function is called with the file or URL.  The external player process is stopped when the presentation quits when it was started from a command string or returned by the function.

** Playing a recorded keyboard macro

A demo can replay a keyboard macro.  The simplest form runs the macro in the side pane; if a demo buffer is already visible it is used, otherwise a scratch buffer is created:

#+begin_src org
* Self-playing macro
#+DEMO: macro:my-demo
#+end_src

To record and name a macro:

1. Press =F3=, perform the steps you want to demonstrate, then press =F4=.
2. Name the macro with =C-x C-k n=, for example =my-demo=.
3. Save it for later sessions with =M-x insert-kbd-macro RET my-demo RET= and put the generated form in your init file.

Macros stored in a register work too.  Use =C-x C-k x= to store the last macro in a register, then refer to it as =macro:register:a=.

A =DEMO-MACRO= property or =#+DEMO-MACRO:= line plays a macro after the slide's =DEMO= buffer has been shown.  This is the natural pairing for a live shell, REPL, or file buffer:

#+begin_src org
* Recorded shell demo
#+DEMO: shell:
#+DEMO-MACRO: my-shell-demo
#+end_src

The macro runs with the demo window selected, so commands that act on the current window or buffer operate on the demo.  The demo-mode keys are temporarily disabled while the macro plays, so recorded =C-c= keys reach the demo buffer's major mode instead of the presentation controls.  Focus returns to the presentation when the macro finishes.  If a shell or REPL needs a moment to start, set =org-slides-demo-macro-delay= to a small number of seconds:

#+begin_src emacs-lisp
(setq org-slides-demo-macro-delay 0.5)
#+end_src

Press =m= in a read-only presentation to replay the slide's macro, or =C-c C-m= to choose a macro.  The same =C-c C-m= binding is available in the demo buffer.

** Preserving the timing of recorded steps

Normal Emacs keyboard macros store only the key events, not the pauses between them.  For a demo that should look like a person typing, record a *timed* macro instead.  The recorder stores each command's keys together with the elapsed time since recording started.

Start recording with:

#+begin_src org
M-x org-slides-timed-macro-start
#+end_src

Perform the steps you want to demonstrate, then stop with:

#+begin_src org
M-x org-slides-timed-macro-stop
#+end_src

Inside a presentation or demo buffer, =C-c C-t= toggles timed recording.  It is best to bind =org-slides-timed-macro-toggle= to a key and start/stop with that key.  If you stop with =M-x org-slides-timed-macro-stop=, the =M-x= input itself becomes part of the recording.  Finish recording before saving the macro or inserting its block; otherwise those commands become part of the macro too.  Org-slides refuses to save or insert a timed macro while a recording is active.  Pressing =C-g= cancels and discards the recording in progress.

The most recent recording is in =org-slides-timed-macro-last=.  Save it as a named variable with:

#+begin_src org
M-x org-slides-timed-macro-save RET my-timed-demo RET
#+end_src

Insert a persistent =setq= form into your init file with:

#+begin_src org
M-x org-slides-timed-macro-insert RET my-timed-demo RET
#+end_src

Use the named macro in a slide:

#+begin_src org
* Timed demo
#+DEMO: timed-macro:my-timed-demo

* Timed shell demo
#+DEMO: shell:
#+DEMO-TIMED-MACRO: my-timed-demo
#+end_src

=timed-macro:last= plays the most recent recording in the current session.  Playback uses the recorded delays; set =org-slides-timed-macro-speed= to a value other than 1.0 to speed up or slow down all delays.  A prefix argument to =M-x org-slides-timed-macro-play= prompts for a speed.  Playback is asynchronous: each step runs from a timer and the display is refreshed between steps, so the demo pane remains visible and Emacs is not blocked for the whole recording.  Focus returns to the presentation between steps, so you can keep pressing =SPC= to reveal bullets while the demo runs; moving to another slide stops the playback.  Stop it with =M-x org-slides-timed-macro-stop-playback= or by hiding the demo pane.

The recorder timestamps each command with =pre-command-hook= and =this-command-keys=.  It captures normal typing and minibuffer input, but not keys consumed inside a single command's own loop (for example while =isearch= or =query-replace= is active).  Mouse events may also replay unpredictably.

** Storing macro definitions in the Org file

A macro can live in a named Emacs Lisp source block in the presentation file, so the definition travels with the slides.  For a timed macro, the block should return a list of =(TIMESTAMP . KEYS)= entries:

#+begin_src org
#+NAME: changelog-scroll
#+BEGIN_SRC emacs-lisp :exports none :results silent
(list (cons 0.20 (kbd "C-v"))
      (cons 0.80 (kbd "C-v"))
      (cons 1.60 (kbd "M-v")))
#+END_SRC

* Changelog scroll
#+DEMO: file:/home/jdyer/.emacs.d/offline-packages/local-packages/org-slides/CHANGELOG.org
#+DEMO-TIMED-MACRO: changelog-scroll
#+end_src

The block name must match the name used after =timed-macro:= or in =DEMO-TIMED-MACRO=.  Org-slides evaluates the block when it needs the macro.  A block takes precedence over a variable of the same name, so the Org file remains the source of truth while you edit it.

For a normal keyboard macro, paste the output of =M-x insert-kbd-macro= into a block with the same name as the macro:

#+begin_src org
#+NAME: my-demo
#+BEGIN_SRC emacs-lisp :exports none :results silent
;; Paste the exact output of M-x insert-kbd-macro RET my-demo RET here.
(defalias 'my-demo (kmacro "h i"))
#+END_SRC

* Demo
#+DEMO: file:~/demos/example.py
#+DEMO-MACRO: my-demo
#+end_src

To create the timed block automatically, put point where you want it and run:

#+begin_src org
M-x org-slides-timed-macro-insert-block RET changelog-scroll RET
#+end_src

For a named keyboard macro, use:

#+begin_src org
M-x org-slides-keyboard-macro-insert-block RET my-demo RET
#+end_src

Both commands insert a =#+NAME:= block with =:exports none= and =:results silent=.  The timed version writes the key events as vectors such as =[22]=; you can edit them to =(kbd "C-v")= for readability if you prefer.  The keyboard version inserts the exact output of =insert-kbd-macro=.

The standard-macro block is evaluated when the macro is not already defined.  If you edit the block after the macro has been defined in the same Emacs session, use a new name or evaluate =(fmakunbound 'my-demo)= first.  For timed macros, the block is re-evaluated whenever the macro is resolved.

Use these header arguments:

- =:exports none= keeps the definition out of exported documents.
- =:results silent= keeps evaluation from inserting a result into the Org file.  Org-slides also forces silent results when it evaluates the block.
- =org-slides-hide-noexport-src= is on by default and hides =:exports none= source blocks during the presentation, so the definition does not appear on a slide.  Set it to =nil= if you want such blocks visible while presenting.

Only =emacs-lisp= blocks can be used as macro definitions.  Org-slides evaluates them with Babel confirmation disabled, so only present Org files you trust.

The block can be anywhere in the file, including before the first heading.  It does not need to be on the slide that uses the macro.

** Using a manually split window

If you prefer to set up the layout yourself, split the frame so the presentation is on the left and your demo buffer is on the right.  Put the demo buffer in the right window, select it, and run:

#+begin_src org
M-x org-slides-demo-use-window
#+end_src

That window is adopted as the demo pane for the current presentation.  An adopted window stays attached when you move to slides that have no =DEMO= spec (=org-slides-demo-keep-adopted=, default =t=), so its demo-mode keys keep working.  Pressing =C-c C-d= detaches it without deleting the window, so your manual split survives.  A later =DEMO= spec displays its buffer in the adopted window.  Set =org-slides-demo-keep-adopted= to =nil= if you want an adopted window detached on slides without a demo.

The demo buffer gets its own =org-slides-demo-mode=, so you can drive the presentation without leaving it:

| Key         | Command                                             |
|-------------+-----------------------------------------------------|
| =C-c C-o=   | Return to the presentation window                   |
| =C-c C-d=   | Detach / hide the demo pane                         |
| =C-c C-m=   | Play a keyboard macro in the demo pane              |
| =C-c C-t=   | Start/stop recording a timed macro                  |
| =C-c C-f=   | Reveal next list item, then next page/slide         |
| =C-c C-b=   | Shadow previous list item, then previous page/slide |
| =C-c C-n=   | Next page or slide, keeping focus in the demo       |
| =C-c C-p=   | Previous page or slide, keeping focus in the demo   |
| =C-c C-q=   | Quit the presentation                               |

=C-c C-f= and =C-c C-b= mirror the presentation's =SPC= and =S-SPC= step keys, so you can reveal bullets one at a time while focus stays in the demo.  =C-c C-n= and =C-c C-p= move directly by page or slide.

In the presentation buffer, =d= or =C-c C-d= toggles the pane and =C-c C-o= moves focus to the demo (pressing it again returns to the slide).  When the buffer is writable, =d= inserts its character like the other navigation keys.

The letter, =SPC=, =f=, =S-SPC=, =d=, and =m= keys only navigate while the buffer is read-only.  Turn off =org-slides-read-only-on-start= or use =C-c C-w= to edit, then use the arrow keys or =C-c C-n= / =C-c C-p= to navigate.

Some GUI and terminal setups deliver Shift+Space as plain Space, so =S-SPC= can trigger the forward step.  In that case use =b=, =S-TAB=, =Backspace=, or =C-c C-b= for the backward step; =b= and =Backspace= retain their normal editing behavior when the buffer is writable.  =n=/=p= and the arrow keys move directly between pages or slides and bypass any unrevealed list items; =SPC=/=f= and =S-SPC=/=b= step through those items first.  In read-write mode, =f=, =d=, and =m= insert their characters like any other letter.

* Customization

#+begin_src emacs-lisp
(setq org-slides-text-scale 5)          ; starting scale
(setq org-slides-scale-on-start t)      ; enlarge on start
(setq org-slides-display-inline-images t)
(setq org-slides-read-only-on-start t)
(setq org-slides-hide-cursor-on-start t)
(setq org-slides-hide-stars-in-headings t)
(setq org-slides-hide-noexport-src t)   ; hide :exports none blocks
(setq org-slides-startup-folded nil)    ; fold each slide on navigation
(setq org-slides-auto-page t)           ; page tall slides in one window
(setq org-slides-page-style 'scroll)    ; or 'split (experimental)
(setq org-slides-page-indicator 'always) ; 'split for only multi-page, nil off
(setq org-slides-page-break-at-headings t)
(setq org-slides-incremental-bullets t) ; SPC/f and S-SPC/b step items
(setq org-slides-demo-pane t)           ; allow per-slide demos
(setq org-slides-demo-width 0.4)        ; frame fraction or columns
(setq org-slides-demo-side 'right)      ; or 'left
(setq org-slides-demo-default nil)      ; e.g. "buffer:*scratch*"
(setq org-slides-demo-keep nil)         ; keep demo on slides without one
(setq org-slides-demo-keep-adopted t)   ; keep a manually adopted demo
(setq org-slides-demo-video-backend 'auto)
(setq org-slides-demo-video-player nil) ; e.g. "mpv --no-terminal"
(setq org-slides-demo-macro-delay 0)    ; wait before playing DEMO-MACRO
(setq org-slides-timed-macro-speed 1.0) ; 1.0 = recorded timing
(setq org-slides-demo-kill-buffers t)   ; clean temp demo buffers on quit
#+end_src

Unrevealed list items use the =org-slides-bullet-shadow= face, which inherits =shadow= by default.  Customize that face to change the dimmed text.  Set =org-slides-incremental-bullets= to =nil= to reveal all list items at once.  With split-page mode, items are collected per page; with scroll pagination, they are collected for the whole logical slide.  Reveal state is stored per slide and page, so once an item has been revealed it stays revealed when you navigate away and return with =n=/=p= or =SPC=/=S-SPC=.

=org-slides-page-indicator= accepts =always= (default: every slide, including single-page slides and the title slide), =split= (only when a slide has more than one page), or =nil=.  The indicator belongs to the split-page style; scroll mode does not show page numbers.

=org-slides-page-indicator-format= controls the mode-line format.  Its four arguments are current slide, current page, total slides, and total pages in the current slide:

#+begin_src emacs-lisp
(setq org-slides-page-indicator-format "%d.%d / %d.%d") ; default
#+end_src

* Hooks

- =org-slides-mode-hook= runs when the minor mode is enabled or disabled.
- =org-slides-after-navigate-functions= is an abnormal hook called with the buffer name and current heading after the presentation starts or changes slides.  It is not called when moving between pages of the same slide.

For example, refresh =org-table-fit= overlays after each slide change:

#+begin_src emacs-lisp
(add-hook 'org-slides-after-navigate-functions
          (lambda (&rest _)
            (when (and (bound-and-true-p org-table-fit-overlay-mode)
                       (fboundp 'org-table-fit-refresh-overlays))
              (org-table-fit-refresh-overlays))))
#+end_src

* Differences from org-present

- Backward navigation is bound by default to =p= and the left arrow; =S-SPC= steps backward through list-item reveals and then pages.
- Navigation keys are editable-aware: they insert characters when the buffer is writable and navigate when it is read-only.
- Complete =#+= lines are hidden together with their newlines, removing the blank lines upstream leaves around source-block delimiters.
- Literal =#+= lines inside block contents are not hidden.
- Overlay lists and cursor caches are buffer-local.
- The previous text scale is restored on quit.
- Tall slides are automatically paged in a single window; org-present just narrows to the slide and lets the overflow run off the bottom.
- List items can be revealed one at a time with =SPC=/=f= and re-shadowed with =S-SPC=/=b=; nested items step individually.
- An experimental split-page style narrows to each computed page, shows only that page's content, and reports =SLIDE.PAGE / TOTAL-SLIDES.TOTAL-PAGES= in the mode line.
- A per-slide demonstration pane can show an Emacs buffer, file, URL, video, shell command, or Lisp-produced buffer beside the presentation.
- The one-page view is respected by next/previous navigation.
- Modern Org calls are used (=org-get-previous-sibling=, =outline-show-all=).
- Setup and teardown are handled by the minor mode itself, so no mode hooks are required just to display images, hide the cursor, or make the buffer read-only.
