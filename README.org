#+title: org-slides
#+author: James Dyer
#+language: en
#+options: toc:nil num:nil

Minimalist presentation mode for Org buffers, derived from
[[https://github.com/rlister/org-present][org-present]].

Each top-level heading is one slide; the text before the first heading is the
title slide.  Nested headings stay on their parent slide.

* Features

- Default forward/backward keys: =n= / =SPC= / right arrow forward,
  =p= / =S-SPC= / left arrow backward.
- =q= quits, =g= and =G= jump to the first and last slide.
- In read-write mode the letter, space, and quit keys insert their characters
  instead, so the buffer remains editable.  =C-c C-n= and =C-c C-p= always
  navigate.
- Hides leading heading stars, complete =#+= keyword lines, and emphasis
  markers.  Hiding a complete =#+= line also hides its newline, so
  =#+begin_src= / =#+end_src= delimiters do not leave blank lines around
  source blocks.
- Literal =#+= lines inside source, example, export, comment, quote, verse,
  center, special, and dynamic blocks are left visible.
- Long slides are paged automatically, one screenful at a time, in the same
  window.  The end of the slide is never cut off; =n=/=p= move through the
  pages and then to the next/previous slide.
- Experimental split-page mode (=org-slides-page-style= set to =split=)
  narrows to one computed page at a time, shows only that page's content,
  and displays =SLIDE.PAGE / TOTAL-SLIDES.TOTAL-PAGES= (for example =2.3 / 5.4=) in the mode line.  The title page is slide 0 and top-level headings are numbered 1, 2, 3, ... in document order.  The indicator is shown on every slide by default.  Page breaks fit the window,
  prefer to start at a nested heading, and can be recomputed after a resize
  or text-scale change.
- The text scale in use before the presentation is restored on quit.
- Overlay and cursor state is buffer-local, so multiple presentations do not
  clobber each other.
- Optional one-page view with =C-c C-1=; this disables automatic paging and
  shows the whole buffer.

* Installation

Requires Emacs 27.1+ and Org 9.4+.  The package is a single file.  Add its
directory to =load-path= or use =use-package=:

#+begin_src emacs-lisp
(use-package org-slides
  :load-path "~/.emacs.d/local-packages/org-slides"
  :commands org-slides-start
  :bind (:map org-mode-map
              ("C-c s p" . org-slides-start)))
#+end_src

In the offline toolkit the package lives under
=local-packages/org-slides= and is loaded automatically by the rendered
=init.el= when present.

* Usage

Open an Org file and run =M-x org-slides-start= (or =C-c s p= if you added the
binding above).  The current slide is narrowed to the window and the text is
enlarged.  If a slide is taller than the window, =n= first scrolls through it
one screenful at a time; another =n= at the end moves to the next slide.
=p= walks back through those pages.  At the last page of the last slide, =n=
stays put and reports the end of the presentation instead of wrapping back to
the start of the same slide.  Use the navigation keys below.  =q= or
=C-c C-q= quits.

For the experimental page-narrowing style, set:

#+begin_src emacs-lisp
(setq org-slides-page-style 'split)
#+end_src

Each tall slide is then split into pages that fit the window.  Only the
current page's content is displayed, and the mode line shows =SLIDE.PAGE / TOTAL-SLIDES.TOTAL-PAGES= (for example =1.2 / 5.3=).  The total slide count is the number of top-level headings; the title page is slide 0 and is not included in that total.  By default the indicator is shown on every slide, including single-page slides and the title slide; set =org-slides-page-indicator= to =split= to show it only when a slide has more than one page.
Pages break at line boundaries; when possible, a break is moved back to a
nested heading so the heading starts the next page.

* Default keys

| Key                 | Command                            |
|---------------------+------------------------------------|
| =n= / =SPC=         | Next page / next slide             |
| =p= / =S-SPC=       | Previous page / previous slide     |
| =right=             | Next page / next slide             |
| =left=              | Previous page / previous slide     |
| =next=              | Next page / next slide             |
| =prior=             | Previous page / previous slide     |
| =g=                 | First slide                        |
| =G=                 | Last slide                         |
| =q=                 | Quit                               |
| =C-c C-n=           | Next page / next slide             |
| =C-c C-p=           | Previous page / previous slide     |
| =C-c C-q=           | Quit                               |
| =C-c C-= / C-c C--= | Increase/decrease text size        |
| =C-c C-r / C-c C-w= | Read-only / read-write             |
| =C-c C-1=           | Toggle the one-page view           |
| =C-c <= / =C-c >=   | First/last slide                   |

The letter and =SPC= keys only navigate while the buffer is read-only.  Turn
off =org-slides-read-only-on-start= or use =C-c C-w= to edit, then use the
arrow keys or =C-c C-n= / =C-c C-p= to navigate.

* Customization

#+begin_src emacs-lisp
(setq org-slides-text-scale 5)          ; starting scale
(setq org-slides-scale-on-start t)      ; enlarge on start
(setq org-slides-display-inline-images t)
(setq org-slides-read-only-on-start t)
(setq org-slides-hide-cursor-on-start t)
(setq org-slides-hide-stars-in-headings t)
(setq org-slides-startup-folded nil)    ; fold each slide on navigation
(setq org-slides-auto-page t)           ; page tall slides in one window
(setq org-slides-page-style 'scroll)    ; or 'split (experimental)
(setq org-slides-page-indicator 'always) ; 'split for only multi-page, nil off
(setq org-slides-page-break-at-headings t)
#+end_src

=org-slides-page-indicator= accepts =always= (default: every slide,
including single-page slides and the title slide), =split= (only when a slide
has more than one page), or =nil=.  The indicator belongs to the split-page
style; scroll mode does not show page numbers.

=org-slides-page-indicator-format= controls the mode-line format.  Its four
arguments are current slide, current page, total slides, and total pages in
the current slide:

#+begin_src emacs-lisp
(setq org-slides-page-indicator-format "%d.%d / %d.%d") ; default
#+end_src

* Hooks

- =org-slides-mode-hook= runs when the minor mode is enabled or disabled.
- =org-slides-after-navigate-functions= is an abnormal hook called with the
  buffer name and current heading after the presentation starts or changes
  slides.  It is not called when moving between pages of the same slide.

For example, refresh =org-table-fit= overlays after each slide change:

#+begin_src emacs-lisp
(add-hook 'org-slides-after-navigate-functions
          (lambda (&rest _)
            (when (and (bound-and-true-p org-table-fit-overlay-mode)
                       (fboundp 'org-table-fit-refresh-overlays))
              (org-table-fit-refresh-overlays))))
#+end_src

* Differences from org-present

- Backward navigation is bound by default to =p=, =S-SPC=, and the left arrow.
- Navigation keys are editable-aware: they insert characters when the buffer
  is writable and navigate when it is read-only.
- Complete =#+= lines are hidden together with their newlines, removing the
  blank lines upstream leaves around source-block delimiters.
- Literal =#+= lines inside block contents are not hidden.
- Overlay lists and cursor caches are buffer-local.
- The previous text scale is restored on quit.
- Tall slides are automatically paged in a single window; org-present just
  narrows to the slide and lets the overflow run off the bottom.
- An experimental split-page style narrows to each computed page, shows only
  that page's content, and reports =SLIDE.PAGE / TOTAL-SLIDES.TOTAL-PAGES=
  in the mode line.
- The one-page view is respected by next/previous navigation.
- Modern Org calls are used (=org-get-previous-sibling=,
  =outline-show-all=).
- Setup and teardown are handled by the minor mode itself, so no mode hooks
  are required just to display images, hide the cursor, or make the buffer
  read-only.
